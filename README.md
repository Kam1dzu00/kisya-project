# Kisya Project

Публичный сайт Telegram-бота для поиска работы **[@KisyaProject_Bot](https://t.me/KisyaProject_Bot)**: https://kam1dzu00.github.io/kisya-project/

Kisya Project собирает свежие вакансии с бирж, сайтов работодателей и более 700 Telegram-каналов и присылает только подходящие под анкету. Описание для ИИ-ассистентов: [llms.txt](llms.txt).

Сайт собирается из `milka/site/` основного проекта (`node milka/site/build.mjs <out> <url>`).
